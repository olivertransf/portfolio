# Portfolio

Personal site for Oliver Tran — projects home page.

Stack: Next.js, React, Tailwind CSS. Deployed on Vercel.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
| ------- | ----------- |
| `npm run dev` | Dev server (Turbopack) |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | ESLint |

## Project data

Featured work and social links live in [`lib/data.ts`](lib/data.ts). Static assets are under `public/`.
